## Коротко

* **Что:** веб-сервис, REST API, Telegram-бот и ИИ-агент поверх единой базы событий культуры Башкортостана. Источники данных: culture.ru, Яндекс Афиша, Kassir.ru (плюс адаптеры KudaGo и произвольных сайтов).
* **Стек:** Python 3.12, FastAPI, SQLAlchemy (SQLite), aiogram 3, Google Gemini, Tailwind CSS, чистый JS без сборщика.
* **Адреса:** сайт и мини-приложение https://195-209-220-227.sslip.io, бот @BashSZbot, локально http://localhost:8000.
* **Уровень по ТЗ:** 2 («Сайт»); что ещё не закрыто, описано в [upd.md](../upd.md).
* **Запуск:** `docker compose up --build` (сайт и API на http://localhost:8000), подробности в [README](../README.md).
* **Тесты:** `python -m pytest`, сейчас 384 штуки.
* **Самое важное, что нужно знать:** бот и ИИ с сервера работают только через прокси на домашнем компьютере (обратный SSH-туннель). Нет туннеля: бот молчит, чат на сайте отвечает по правилам. Подробности в [разделе 04](04-сервер-и-эксплуатация.md).
