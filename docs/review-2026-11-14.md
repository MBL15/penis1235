## 4. MCP-сервер (сделано в этой ветке)

`python -m app.mcp_server`: протокол MCP поверх stdio, без новых зависимостей. Инструменты только для чтения: `search_events`,
`get_event`, `find_similar`, `get_venue_schedule` (те же функции, что у агента, с той же нейтрализацией инъекций в описаниях),
`list_facets`, `plan_day`. `subscribe` и `save_feedback` не вынесены: у MCP-клиента нет кнопки подтверждения (§6.5).
В каждом событии ссылка на карточку сервиса. Тесты: `tests/test_mcp_server.py` (8 шт.). Проверен вживую на локальной базе.
