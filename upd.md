1. **Уровень не объявлен.** ТЗ (§1, §5) требует зафиксировать выбранный уровень в README. В README и `docs/` слова «уровень» нет.
2. **Фактически ни один уровень не закрыт целиком.**

   - Уровень 4 («Контур»): нет проверки перед публикацией, очереди модерации, планировщика «Выходной день», расписания, набора из 60 запросов и отчёта по метрикам.

   - Нет пометки, что сервис не официальный сервис министерства. На главной написано «из официальных источников», хотя большая часть записей из Яндекс Афиши и Kassir.
   - В коде остался генератор выдуманных событий `app/seed.py`. В рабочей базе демо-событий 0.
4. **Даты врут для серий сеансов.** События из kassir.ru записаны как один длинный интервал, поэтому поиск «в субботу» показывает события других дней (см. B-11).
